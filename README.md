# Key Club Email Editor

A Google-Docs-style editor for GCS Key Club emails. Open `index.html` and start typing.

- **Templates:** Announcement, Fee reminder, Blank. Pick one under the subject line.
- **Edit anything:** click to type. The toolbar has font size, bold/italic/underline, colors (plus the Key Club palette), alignment, lists, links and images.
- **Sections:** hover a section to move it up or down, duplicate it or delete it. **＋ Insert** adds paragraphs, info tiles, numbered lists, callout boxes, buttons, images, dividers.
- **Images:** use the image button, paste one, or drag it in. Click an image to resize, align, link or replace it.
- **Autosave:** your edits stay in this browser, kept separately for each template. *Export → Reset* starts that template over.

## Sending it

1. Click **Copy for Gmail**.
2. In Gmail, open Compose and press **Ctrl+V**.
3. *Export → Copy subject line* for the subject.

*Export → Download .html* saves the email as a standalone file.
